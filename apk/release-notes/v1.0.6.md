# EEPROM Studio 1.0.6 — CH341A USB detection recovery (experimental beta)

This signed update addresses CH341A USB reconnection and detection errors seen in version 1.0.5. It preserves the existing XP400 drivers and the CH341A SPI/I2C memory reader.

- Scans the Android USB device list again after launch and while the app is in the foreground.
- Reports the actual USB vendor/product ID if a CH341A or other USB device is connected but not recognized.
- Explains CH341 **serial mode** (1A86:5523) versus the supported EEPROM **memory mode** (1A86:5512). Serial mode is diagnostic-only, not a valid EEPROM programmer connection.
- Allows a single bounded retry after failed CH341A interface opening when Android permission is already granted; permission denials do not trigger repeated prompts.
- Keeps Android's normal USB chooser/default-app and permission flow. XP400 EEPROM, MCU and key functions remain unchanged.

**Bench-test warning:** A valid Android build and matching signing certificate do not prove detection on every phone or programmer. If CH341A still is not detected, tap **Connect & identify** and **Save log**; the log shows which USB ID Android enumerated. Do not attempt EEPROM writes from CH341A (still disabled), and confirm the actual chip-adapter voltage before reads.
