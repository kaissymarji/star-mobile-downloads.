# EEPROM Studio 1.0.5 — USB programmer auto-detection fix (Experimental Beta)

**Android USB attachment and reconnection reliability update** for supported XP400 and CH341A programmers. This APK is signed with the same production signing certificate as 1.0.4 and installs without uninstalling.

- **Open on USB plug-in:** Android can offer EEPROM Studio when a supported **CH341A memory/parallel mode (1A86:5512)** or **XP400 (0483:5740)** is plugged in, even if EEPROM Studio was closed.
- **CH341A auto-detect:** Handles launch, in-app attach, and already-connected devices; clears stale USB selections that previously blocked reconnection. Opens only the USB interface; it does **not** automatically read or write any chip.
- **XP400 preserved:** Recognizes attachment, but waits for the user's **Connect & identify** action. Existing XP400 EEPROM, MCU, key/transponder and write capabilities are not changed.
- **CH341A protections retained:** Unimplemented operations remain disabled; suspicious all-FF/all-00/long-FF-prefix dumps still require explicit review before export.
- **Android controls default-app choice:** If asked, select EEPROM Studio and **Always**. A pre-existing default in another programmer app may need to be cleared in Android's App settings. This update cannot override another app's default or bypass USB permission.

**Compatibility:** The auto-launch filter matches only these two USB hardware IDs. It intentionally does not launch for arbitrary USB devices, serial-only CH341/CH340 modes, or unsupported programmers.

**Hardware beta:** Software/build/signature checks passed, but automatic launch and CH341A chip reads still require testing with real devices. Check voltage and adapter orientation; do not depend on unverified dumps for critical work.
