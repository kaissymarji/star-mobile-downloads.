# EEPROM Studio 1.0.3 — CH341A experimental beta

**EXPERIMENTAL HARDWARE BETA — NOT VERIFIED ON PHYSICAL CH341A CHIPS.**

This Android update adds CH341A USB programmer detection and a separate, capability-gated read-only driver while preserving XP400 support. The app remains signed with the existing production certificate so it can update 1.0.2 in place.

### What's new
- Automatic CH341A memory-mode detection on USB OTG (USB VID:PID `1A86:5512`), including permission handling and disconnect state.
- CH341A SPI 95xxx and basic I²C 24Cxx read paths implemented with two-pass byte comparison (experimental; device behavior not yet bench validated).
- Unsupported chip families and functions are displayed as disabled. CH341A EEPROM write, erase/FF-fill, MCU/BDM, transponder/key scan remain unavailable.
- When XP400 is connected, its existing operations and menus are preserved; no CH341A protocol is used on XP400.
- Conservative failure behavior: no accepted CH341A dump unless independent whole-chip reads match.

### Important safety notes
- **The CH341A board's voltage must be measured first**. Some CH341A boards have unexpected 5V I/O. Never connect an unknown board directly to a 3.3V EEPROM or a powered vehicle module.
- Start with a spare, known-good 95xxx or 24Cxx chip. Compare the app's result to a trusted PC programmer dump.
- Reads only: CH341A programming, erase, ECU unlocking or security bypass are **not supported**.
- Do not rely on experimental CH341A reads for customer work until hardware validation is complete.

**Installation:** Same package ID `com.starmobileservice.xp400studio`. Android can install this APK over signed 1.0.2 without uninstalling, and prompts for approval. Keep backups.

**Validation performed:** Android compilation and signing; identical permanent certificate; emulator in-place upgrade and retention of app data; protocol and UI gating tests. **No physical CH341A/EEPROM verification yet.**
